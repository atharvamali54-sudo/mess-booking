# 🍱 Mess Booking Platform (मेस आणि फूड बुकिंग प्लॅटफॉर्म)

एक आधुनिक वेब आणि मोबाईल ॲप्लिकेशन, जिथे विद्यार्थी आणि बॅचलर्स जेवण (थाळी), मेस पास, आणि स्नॅक्स शोधू आणि ऑर्डर करू शकतात. मेस मालक स्वतःचे मेनू आणि ऑर्डर्स थेट मॅनेज करू शकतात.

---

## 🌟 वैशिष्ट्ये (Key Features)

### १. विद्यार्थी आणि बॅचलर्ससाठी (For Students & Professionals)
- **मेस शोधणे**: परिसरातील सर्व मेस (Veg / Non-Veg / शुद्ध शाकाहारी) मेनूसह पाहणे.
- **ऑर्डर आणि बुकिंग पद्धती**:
  - **Self-Pickup**: मूळ किंमत (उदा. ₹८०) - टोकन घेऊन मेसवरून स्वतः जेवण घेणे.
  - **Order / Delivery**: मूळ किंमत + **₹५ एक्स्ट्रा** (उदा. ₹८० + ₹५ = ₹८५).
- **डिजिटल मेस पास (Digital Attendance & QR)**:
  - शिल्लक जेवणाची संख्या आणि QR कोड.
- **Skip Meal / Leave Notice**:
  - गावी जाताना किंवा बाहेर जेवताना २ तास आधी कळवून जेवण पुढे कॅरी-फॉरवर्ड करण्याची सोय.

### २. मेस मालकांसाठी (For Mess Owners)
- **लाईव्ह डॅशबोर्ड**: Self-Pickup व Delivery च्या सर्व ऑर्डर्स टोकन नंबरसह पाहणे.
- **मेनू अपडेट**: रोजचा दुपारचा व रात्रीचा मेनू, भाजी, भाकरी आणि गोड पदार्थ एका क्लिकवर बदलणे.
- **कमाई व सबस्क्रायबर्स**: रोजची कमाई, एकूण थाळ्या आणि ॲक्टिव्ह सबस्क्रायबर्स ट्रॅक करणे.

## 🚀 कसे चालवावे (How to Run Locally)

```bash
# प्रोजेक्ट डिरेक्टरीमध्ये जा
cd "C:\mess booking"

# डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev
```

ब्राउझरमध्ये `http://localhost:5173` उघडा.
